## What Qloo contributes

Qloo supplies identities, taste-tag resolution, cross-domain replacement discovery and query-relative cultural order. Rules alone can test city, country, type and plan size when facts exist; they cannot supply the recorded artist-to-place relationship or that query's ordering.

The frozen synthetic holdout still has **6/50** scored plans with a priority difference and **0/50** retained-set differences. P07 adds **one real, source-corroborated replacement**, not a population-level quality percentage. There is still no pair of independently corroborated P07 candidates for a real eligible-pair priority comparison. **INDEPENDENT_QUALITY_GAIN=NOT_ESTABLISHED.**

The four conclusions stay separate: cultural evidence coverage, candidate priority change, valid repair change and independent quality gain. A real repair is a verified replacement under the declared constraints; it does not establish personal liking, evening suitability, opening hours, tickets or accessibility.

## Display and operational boundary

The [official developer guide](https://docs.qloo.com/reference/qloo-llm-hackathon-developer-guide), re-read for this sprint, permits private server-side caching and forbids response data in a public repository. It does not establish a sufficiently clear public-display permission for this release. These are separate scopes:

| Surface | Current decision |
| --- | --- |
| Private server cache | Captures retained privately, integrity checked |
| Public source and review ZIP | No raw responses, private provider IDs, facts, request URLs, approval tokens or private source fingerprints |
| Owner-local recorded UI/export | Available in the recorded-local profile with private evidence; exports remain private |
| Public response projections, affinity values, screenshots or recordings | Not enabled or exported pending display permission |
| Fresh production Qloo access | Not authorized; production-live is refused |

Compliant judge path still needs an external decision: obtain written permission for the exact projected fields and a judge-access arrangement; then separately approve and review the smallest permitted release configuration. A synthetic-only host is useful for workflow judging but is **not declared sufficient** to demonstrate the real integration. No public replay or live mode is silently enabled.
